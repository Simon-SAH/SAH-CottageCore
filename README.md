## 🌿 About the Mod

**CottageCore** is part of the SAH Project and focuses on immersive farming, fermentation, and cooking mechanics. The mod introduces:

- 🍇 New crops: **grapes**, **grape seeds**
- 🛢️ A **Fermentation Barrel** block with unique particle effects
- 🧪 Early-stage fermentation mechanics (with vapor particles)
- ⚙️ Future support for brewing, distilling, cooking, and crop variety

Designed for compatibility with Minecraft `1.21.10` using the **Fabric Loader**.

> **Note:** This is an early development version. Features and structure may change significantly.

---

## 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/) and [Fabric API](https://modrinth.com/mod/fabric-api)
2. Place the `sahfarming` mod `.jar` file into your `mods` folder
3. Launch Minecraft 1.21.10 with Fabric
